# Contributing

Thank you for helping. These examples are a copy: they live in Videxo's own source, where the docs,
the downloads and the tests use them, and every update replaces the files here. So every fix is
made there, and pull requests here are closed with thanks.

- **A problem with an example**: open an issue. Name the folder, what you ran and what happened,
  with the error's `code` and `detail` when the API answered one. We fix it at the source and it
  arrives here with the next update.
- **A question about the API or your account**: see [Get help](https://videxo.io/docs/support).
- **A security problem**: do not open an issue; email [hello@videxo.io](mailto:hello@videxo.io).

Never post an API key or a webhook signing secret, in an issue or anywhere else. If one was exposed,
revoke the key in the dashboard under **API keys**, or rotate the secret under **Webhooks**.
